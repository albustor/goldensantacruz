# Memoria del Proyecto — Golden Sport Academy Santa Cruz

## Registro de Decisiones de Arquitectura (ADR)
- **Octubre 2026 — Adopción de Simplicidad Radical y Descarte de Sobre-Ingeniería**:
  - Se define la academia como una herramienta de servicio ágil para atletas y padres de familia.
  - Se descartan animaciones y gráficos 3D pesados a favor de fotos reales de alta calidad y carga instantánea.
  - El flujo de transmisión multicámara se mantiene en pausa para priorizar la captación de nuevos inscritos y la cobranza sin fricción por WhatsApp.
